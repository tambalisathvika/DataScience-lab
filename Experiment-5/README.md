## 🔬 Experiment Overview
This laboratory module explores statistical data visualization utilizing Python, Pandas, Matplotlib, and Seaborn:
- **Task 5A:** Multi-panel line plots with titles, axis labels, custom ticks, arrow annotations, and 300 DPI image file export.
- **Task 5B:** Discrete categorical visualization with grouped side-by-side and vertically stacked bar charts.
- **Task 5C:** Empirical value frequency histograms paired with Kernel Density Estimation (KDE) continuous curves.
- **Task 5D:** Bivariate scatter plots, relationship diagnosis, and Pearson linear correlation coefficient calculation.
- **Task 5E:** Five-number summary categorical box plots across multiple departmental groups.

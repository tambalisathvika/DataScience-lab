# MBU DS LAB — Data Science Laboratory

Official Data Science Digital Laboratory platform for Mohan Babu University (MBU), School of Computing, Department of Data Science.

## Overview
An interactive academic digital laboratory environment designed for hands-on experimentation with data science workflows, time series forecasting, preprocessing pipelines, and practical evaluation.

### Key Laboratory Features
- **Experiment Practicals (1 through 6)** with comprehensive sub-tasks (e.g. Experiment 6 Time Series Analysis 6A–6G).
- **Interactive Code Editor & Kernel Simulator** for Python, Pandas, and NumPy scripts.
- **Curriculum-Aligned Modules** based on university syllabus and core textbooks.
- **Visual Matplotlib Plots Preview** for temporal sequences, stationarity diagnostics, and seasonal decomposition.
- **Continuous Internal Evaluation (CIE)** rubrics and viva voce questions.

---

## Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/tambalisathvika/DataScience-lab.git

# Navigate to project directory
cd DataScience-lab

# Install dependencies
npm install

# Start development server
npm run dev
```

The application runs locally on `http://localhost:3000/`.

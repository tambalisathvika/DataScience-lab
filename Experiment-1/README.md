## Overview
This laboratory module covers reading and writing datasets across common file storage protocols:
- **1A:** Reading & Writing text delimited data (CSV / TSV / TXT)
- **1B:** Hierarchical JSON serialization and deserialization
- **1C:** Multi-sheet Microsoft Excel (`.xlsx`) reading and authoring

## Scripts
- `1A_read_write_text.py`: Plain text and CSV ingestion with Pandas `read_csv()`
- `1B_read_write_json.py`: JSON parsing with `json.dump()` and `pd.json_normalize()`
- `1C_read_write_excel.py`: Multi-sheet Excel workbook operations with `pd.ExcelWriter`
